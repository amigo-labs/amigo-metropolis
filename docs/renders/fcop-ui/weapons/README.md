# FCOP weapon panels & icons (reference)

The ten catalogue weapons' febmp pictures, kept here for docs and offline
inspection; the client ships them as the front end's `bmpNNN.png` under
`packages/client/public/ui/frontend/`. Source: `missions/febmp.bin` → `extracted/frontend/` in
the RE repo. Bar lengths on the panels are the published rate/damage values
(55 px trough); see `docs/specs/rules.md` §2.
